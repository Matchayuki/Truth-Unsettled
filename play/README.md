# 真理未决 · 独立游玩版

这是独立的局域网游玩页面，不与游戏介绍页共用网页、脚本或样式。支持 **4—8 名玩家 + 1 名不参战主持人**。

## 快速开局

1. 双击 `start-lan.cmd`。脚本会优先使用已安装的 Node.js，也会尝试使用 Codex 附带的 Node.js。
2. 浏览器会自动打开游玩页；保持启动窗口开启。
3. 主持人选择人数并创建房间，再把页面显示的局域网地址分享给玩家。
4. 玩家连接同一 Wi-Fi，在自己的手机或电脑打开该地址，输入房间号和昵称。
5. 人数到齐后由主持人开始游戏。

如果浏览器没有自动打开，请访问 `http://localhost:4317`。不要直接打开 `index.html`，否则浏览器无法连接创建房间所需的本机服务。如果 Windows 防火墙询问是否允许访问局域网，请允许专用网络。此页面无需外网服务；玩家设备和主持人电脑需要连在同一个局域网。

## 页面分工

- **玩家页**：只展示自己的阵营、手牌、契约和投票。其他存活玩家的阵营与投票不会发送到玩家页面；公开出牌、心智和结算记录会同步给全桌。
- **主持人页**：可以查看所有身份、契约、手牌、秘密夜间选择和个人投票，并按阶段推进游戏。
- 主持人页面上的“流程控制 / 私密信息 / 玩家状态 / 结算记录”彼此分开；玩家页只显示当前阶段能执行的行动。

## 本版本的结算范围

页面自动处理身份与手牌分配、秘密夜间目标、心智变化、论证标记、诘问响应、辩论对决、装备槽、秘密投票汇总和轮次推进。每回合可以连续出多张牌。

角色技能以及其他基础牌、锦囊牌和议题牌的特殊效果，由主持人依据牌面文字裁定；“玩家状态”页可辅助调整心智、摸牌、弃牌、处理论证标记、装备和投票，或判定出局。游士契约的终局检查会自动处理常见目标，主持人仍需核对具体情形。它适合桌面试玩与规则打磨，尚不是全自动裁判。

## 隐私与运行

牌局数据只保存在运行中的本机服务内存中。关闭服务窗口会结束当前房间；刷新网页可用当前浏览器会话重新连接。玩家应各自使用设备或独立浏览器会话，不要把玩家页面投到公共屏幕。

只有一台电脑运行服务即可；其他设备访问主持人启动时显示的 `http://局域网地址:4317`。不需要部署云服务器，也不需要登录账号。
