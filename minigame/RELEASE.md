# 真理未决 · 发布上线清单

> 当前状态：代码、云函数、PostgreSQL 已跑通；开发者工具模拟器可创建房间。
> 发布不是点一次“上传”就结束，小游戏还需要**备案、资质、类目、隐私、适龄提示**，审核通过后才能发布。

## 一、发布前必须确认的 3 个技术点

### 1. 云环境绑定与真机验证（最高风险）

当前客户端连接的是腾讯云 CloudBase 环境：

```
truth-unsettled-d5fu693h4e728350
```

模拟器能调用，不代表所有微信用户都能调用。发布前必须确认：

- [ ] CloudBase 控制台 → 环境 → 设置 → 微信小程序/小游戏，已绑定 AppID `wx62c36cb736876216`；
- [ ] 用手机微信扫描开发者工具的「预览」二维码，能正常进入游戏；
- [ ] 用**另一个微信账号**（体验成员）扫码，能创建/加入房间，且两人的 OpenID 不同。

如果真机报 `env not found`、`permission denied` 或所有玩家 OpenID 相同，先不要上传审核，把错误截图发给开发处理。

### 2. 云函数超时：免费版 3 秒，不能改（代码已适配）

免费版 CloudBase 云函数固定 **3 秒**，后台没有可修改项。不要在这上面卡住。

代码已经做了两层保护：

- 客户端 `js/net.js` 遇到超时/网络错误自动重试 2 次；
- 每次写操作带 `opId`，云函数按 `opId` 去重，重试不会重复建房、出牌、投票。

冷启动超时一次时，第二次通常命中热实例。若三次都失败，游戏会提示“再点一次”。

### 3. 发布配置

- [ ] `project.config.json` 的 AppID 为 `wx62c36cb736876216`；
- [ ] `compileType` 为 `game`；
- [ ] 代码包小于 4MB（当前约 330KB）；
- [ ] 上传前在开发者工具点一次「编译」，确认无报错；
- [ ] 建议把 `libVersion` 从 `latest` 固定为当前稳定基础库版本（例如 `3.17.4`）。

## 二、合规材料（最长路径，今天就启动）

小游戏没有版号时走 **IAA（不接虚拟支付）** 路径：

```
资质审核（1—3 个工作日）
  → 小游戏备案（10—20 个工作日）
  → 小程序备案（10—30 个工作日）
  → 版本审核（约 1 个工作日）
  → 发布
```

有版号则走 IAP/版号路径，可跳过小游戏备案，但仍需小程序备案。

### 1. 先确认账号主体

- [ ] 登录 <https://mp.weixin.qq.com/>，确认「真理未决-哲学桌游」的主体是**个人**还是**企业**。

**个人主体不能选择「文化互动」「角色类」「牌类」三个类目。** 这个游戏是阵营推理桌游，审核很可能要求归到「牌类」或「角色类」；如果是个人主体，可能无法按游戏类目发布，需要考虑企业主体或调整类目（以审核结果为准）。

### 2. 类目

- [ ] MP 后台 → 设置 → 基本设置 → 服务类目 → 游戏；
- [ ] 二级/三级类目要与实际玩法一致（休闲/策略/牌类，按后台可选项）；
- [ ] 个人主体避开角色类、牌类、文化互动。

### 3. 小游戏备案（无版号时）

- [ ] MP 后台 → 账号设置 → 小程序备案 → 小游戏备案 → 前往提交；
- [ ] 选择「情况二：当前及未来均不需要开通虚拟支付」；
- [ ] 准备：游戏名称、主体信息、玩法说明、游戏截图、自审材料；
- [ ] 游戏名称、主体在备案期间不要修改。

### 4. 小程序备案（工信部）

- [ ] MP 后台 → 设置 → 小程序备案 → 去完善；
- [ ] IAA 游戏选择「情况二」；
- [ ] 准备主体证件、负责人信息、域名/服务器信息（使用云开发按后台要求填写）；
- [ ] 管局会发短信核验，务必及时完成。

### 5. 资质审核（IAA）

- [ ] MP 后台 → 设置 → 游戏设置 → 资质管理；
- [ ] 选择「情况二：不需要开通虚拟支付」；
- [ ] 按后台要求上传材料；名称含英文/“软件”/品牌合作时通常需要《计算机软件著作权登记证书》；
- [ ] 有软著就提前准备，没有则按后台提示判断是否必须。

### 6. 隐私保护指引

游戏会让玩家**手动填写昵称**，并保存 OpenID 用于房间身份，需要在 MP 后台披露：

- [ ] MP 后台 → 设置 → 服务内容声明 → 用户隐私保护指引；
- [ ] 声明「用户填写的昵称」和「账号标识（OpenID）」的用途、存储期限；
- [ ] 如使用微信昵称/头像接口，还需声明对应用户信息类型；
- [ ] 审核通过后，可在游戏内用 `wx.openPrivacyContract` 展示。

当前代码没有调用 `wx.getUserProfile`，昵称是玩家自己输入的；仍需在隐私指引中如实披露。

### 7. 适龄提示

- [ ] MP 后台 → 设置 → 游戏设置 → 适龄提示；
- [ ] 按内容选择（建议 12+ 或 16+，以审核要求为准）；
- [ ] 游戏内应在首页/加载页展示适龄提示。

### 8. 内容安全

- [ ] 玩家昵称会展示给其他人，建议接入内容安全检测（`security.msgSecCheck`）或至少过滤网址、联系方式、明显违规词；
- [ ] 哲学议题、历史人物内容避免涉及现实政治、宗教冲突等敏感表达；
- [ ] 准备 3—5 张真实游戏截图（首页、创建房间、等待大厅、牌桌、结算）。

## 三、上传与提审

### 1. 上传代码

- [ ] 开发者工具右上角「上传」；
- [ ] 版本号：`1.0.0`；
- [ ] 项目备注：`首个公开版本：4—8 人哲学阵营推理`；

### 2. 提交审核

- [ ] 开发版本 → 提交审核；
- [ ] 选择游戏引擎（原生 Canvas / 其他）；
- [ ] 完善隐私保护指引、适龄提示、版本说明；
- [ ] 上传宣传图（非必填，但建议）；

- [ ] 提交后等待审核，通常在 1 个工作日左右。

### 3. 发布

审核通过 **不等于** 可以立即发布：

- [ ] 小程序备案必须已完成（管局下发备案号）；
- [ ] 版本审核通过；
- [ ] MP 后台 → 版本管理 → 审核版本 → 发布。

## 五、当前已知风险

1. **环境绑定/真机 OpenID**：模拟器通过不代表线上通过，必须先真机验证。
2. **个人主体类目限制**：可能无法选牌类/角色类，导致无法按当前玩法发布。
3. **备案周期**：无版号 IAA 路径通常 1—2 个月，不是当天能上线。
4. **数据库权限**：当前 `GRANT ALL ... TO PUBLIC` 方便开发，但生产环境建议改为受限角色 + RLS。
5. **昵称内容安全**：目前只做了长度/空值校验，未接微信内容安全接口，审核可能提出要求。
6. **免费版 3 秒超时**：已加客户端重试 + 服务端幂等；极端冷启动仍可能三次失败，提示玩家重点一次。
